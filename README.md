# 🎥 YouTube Video Links Directory

A clean, fast, and responsive web interface designed to organize and share curated YouTube video links, playlists, and video resources in one central place.

## ✨ Features
* 🔗 **Custom Link Hub:** Easily display and structure any YouTube video links.
* 📱 **Fully Responsive:** Smooth layout optimized for mobile, tablet, and desktop screens.
* ⚡ **Fast & Lightweight:** Built using vanilla HTML5, CSS3, and JavaScript—no heavy frameworks required.
* 🌐 **Free Hosting:** Ready to deploy directly with GitHub Pages.

## 🛠️ How to Add Your Own Video Links
1. Open the `script.js` file.
2. Add your video title, category, and YouTube URL into the `youtubeLinks` array:
   ```javascript
   {
       title: "Your Video Title",
       category: "Category Name",
       url: "[https://www.youtube.com/watch?v=YOUR_VIDEO_ID](https://www.youtube.com/watch?v=YOUR_VIDEO_ID)"
   }
